# Introduction 审核清单

> 基于 ieee-mg-writing/static/section-introduction.md 的5层架构检查。

## 结构性检查（5层架构）
- [ ] 1. **Layer 1**: 大背景段是否从宏观到微观
- [ ] 2. **Layer 1**: 是否引用 2-5 篇背景文献
- [ ] 3. **Layer 2**: 技术演进段是否清晰
- [ ] 4. **Layer 2**: 引用密度是否 ≥1/句
- [ ] 5. **Layer 3**: 文献综述是否按主题分类（≥2类）
- [ ] 6. **Layer 3**: 是否覆盖关键和最新文献
- [ ] 7. **Layer 4**: 是否包含 "To the best of our knowledge" 空白句
- [ ] 8. **Layer 5**: 贡献是否以 1)2)3)4) 编号
- [ ] 9. **Layer 5**: 每个贡献是否含"动作+成果"
- [ ] 10. 论文组织段落是否存在

## 风格性检查
- [ ] 11. 引用句式是否多样（避免重复 "the authors in [x] investigated"）
- [ ] 12. 时态是否正确（背景现在时，已有工作过去时）
- [ ] 13. 是否有符号说明段落（如含大量数学符号）
- [ ] 17. 文献综述内部过渡手法是否多样化（避免 ≥3 句连续以单词过渡词 Meanwhile/Furthermore/Additionally/Moreover 开头）

## 格式性检查
- [ ] 14. 文献引用是否全是编号格式 [x]
- [ ] 15. 缩略语首次出现是否已定义
- [ ] 16. 段落间过渡是否自然

## 常见致命问题
| 问题 | 严重性 |
|------|:------:|
| 无贡献编号列表 | 🔴 |
| 无研究空白句 | 🔴 |
| 文献综述未分类 | 🟡 |
| 无论文组织段落 | 🟡 |
| 引用格式不统一 | 🟡 |
| 过度使用单词过渡词（Meanwhile→Furthermore→Moreover→In addition 连锁） | 🟡 |
