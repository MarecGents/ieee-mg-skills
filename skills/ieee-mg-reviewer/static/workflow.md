# 审核工作流

## 标准审核流程

### Step 1：全文通读
快速通读全文，建立整体感知：
- 识别技术主题和研究方向
- 评估整体结构完整性
- 标记明显的结构缺失

### Step 2：逐章审核
按照各 check-*.md 清单逐章检查：

```
check-abstract.md      → 检查摘要的5要素、编号结果和开头模式
check-introduction.md  → 检查引言的5层架构、贡献列表和过渡手法
check-motivation.md    → 检查动机的While开头、4点贡献和空白句式
check-system-model.md → 检查模型符号一致性和逻辑链
check-results.md      → 检查仿真参数表、三段式分析、多因一释、trade-off、双面论证、子图联合分析
check-conclusion.md   → 检查结论时态、未来工作、顺序词串联、实际应用落点、被动确认句式
```

### Step 3：全局检查
- 术语一致性检查（对照 share/terminology.md）
- 缩略语规范检查
- 引用格式统一性
- 时态全局一致性

### Step 4：生成报告
按照 `report-template.md` 格式输出：
```
## Review Report — [论文标题]
### 总体评价
[风格符合度百分比] [总体描述]

### 问题列表（按严重性排序）
#### 问题 #N [严重性] [类别]
**位置**: [章节], 第X句
**原文**: ...
**问题**: ...
**建议**: ...

### 统计摘要
| 严重性 | 数量 |
|--------|:----:|
| 🔴 严重 | X |
| 🟡 中等 | X |
| 🟢 建议 | X |
```
