# Abstract 审核清单

> 基于 ieee-mg-writing/static/section-abstract.md 的逐项检查。

## 结构性检查（10项）
- [ ] 1. 首句是否属于语料高频模式（约 40% 为 "This paper investigates/proposes"；技术主语式 "X has attracted growing interest..."；或让步-转折结构 "Although... + To address these issues"）
- [ ] 2. 是否包含背景句（领域重要性）
- [ ] 3. 是否包含问题/动机句（已有工作不足）
- [ ] 4. 是否包含方法句（we propose/derive/formulate）
- [ ] 5. 是否包含结果句（Numerical results show）
- [ ] 6. 结果是否以 i)/1) 无括号编号
- [ ] 7. 编号结果是否包含≥2条
- [ ] 8. 词数是否在 100-250 范围内
- [ ] 9. 句数是否在 5-12 范围内
- [ ] 10. 是否包含至少一个性能比较

## 风格性检查（5项）
- [ ] 11. 时态是否统一（一般现在时）
- [ ] 12. "we" 密度是否适当（每千词 8-15 次）
- [ ] 13. 是否避免口语化表达
- [ ] 14. 是否避免 "very/obviously/clearly"
- [ ] 15. 是否包含具体数值/百分比

## 格式性检查（3项）
- [ ] 16. 所有缩略语首次出现是否已定义
- [ ] 17. 引用格式是否为 IEEE 编号格式
- [ ] 18. 数学符号是否斜体/粗体规范

## 常见致命问题
| 问题 | 严重性 |
|------|:------:|
| 无编号结果列表 | 🔴 |
| 缺少方法细节（无 we propose/derive） | 🔴 |
| 词数<80或>280 | 🟡 |
| 首句被动开头 | 🟡 |
| 结果模糊（无具体数值） | 🟡 |
