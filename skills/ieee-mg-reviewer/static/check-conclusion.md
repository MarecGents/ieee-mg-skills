# Conclusion 审核清单

- [ ] 1. 开头是否使用语料高频句式（"This paper has investigated/studied..." 或 "In this paper, the ... has/have been investigated..."）
- [ ] 2. 时态是否正确（现在完成时回顾工作）
- [ ] 3. 是否总结了核心工作（做了什么）
- [ ] 4. 是否总结了主要发现（发现了什么，含数值）
- [ ] 5. 与 Abstract 是否有差异（不复读摘要）
- [ ] 6. 是否没有引入新信息或新引用
- [ ] 7. 是否有未来工作方向（1-2句）
- [ ] 8. 未来工作是否具体可行
- [ ] 9. 长度是否在 200-400 词范围内
- [ ] 10. 是否包含 "A promising future research direction is..."
- [ ] 11. 是否使用顺序词串联发现（"Firstly... Secondly... Finally"）
- [ ] 12. 是否有实际应用场景落点（"From the perspective of practical applicability..."）
- [ ] 13. 是否使用被动确认句式（"It has been shown that... / It can be confirmed that..."）

## 常见致命问题
| 问题 | 严重性 |
|------|:------:|
| 时态混用（同一句内完成时与一般现在时/过去时切换） | 🔴 |
| 完全复制 Abstract | 🟡 |
| 无未来工作 | 🟡 |
| 引入新引用 | 🔴 |
| 缺顺序词串联 | 🟢 |
| 无实际应用落点 | 🟢 |
| 缺被动确认句式 | 🟢 |
| 未来工作泛泛而谈 | 🟢 |
