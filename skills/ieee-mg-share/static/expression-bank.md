# 通用句式库

> 基于课题组 21 篇论文语料提取的通用学术句式。不绑定特定章节，适用于全文各处的学术表达。
> 被 ieee-mg-writing 和 ieee-mg-polishing 共同引用。

## 1. 文献引用句式

| 功能 | 句式模板 |
|------|----------|
| **正面引用** | "The authors in [x] proposed/investigated/studied..." |
| **归类引用** | "Prior works have demonstrated that..." |
| **现状描述** | "X has been extensively studied in the context of Y [x], [x]." |
| **历史回顾** | "Early studies [x] focused on ..., while recent works [x] have shifted to..." |
| **对比引用** | "In contrast to [x] which considered ..., this paper..." |
| **文献编号开头** | "In [x], the authors proposed/investigated/introduced..." |
| **开创性工作** | "A seminal work proposed X and designed Y [x]." |
| **被动语态引用** | "X was studied/analyzed/investigated in [x]." |

## 2. 研究空白句式

| 句式模板 | 使用时机 |
|----------|----------|
| "To the best of our knowledge, there is/are no [已有工作] to investigate [缺口]." | 标准空白声明（语料主流，约70%） |
| "However, the unique advantages offered by X remain underutilized in Y scenarios." | 技术未充分利用 |
| "While the aforementioned works have laid a solid foundation for X, [新问题] remains an emerging area of study." | 引出新方向 |
| "Although X has been studied, the integration of X and Y is still in its infancy." | 交叉领域空白 |
| "Despite the promising results of X, the impact of Y on Z remains unknown." | 开放问题 |
| "To the best of our knowledge, there are no existing works to investigate X." | 完全未被研究 |
| "To the best of our knowledge, there is no existing work investigating X." | 同上，单数形式 |
| "This paper presents the first comprehensive analysis of X." | 声称首创性 |
| "X remains an emerging area of study / is still in its infancy." | 领域刚起步 |

## 3. 贡献陈述句式

| 动作 | 句式模板 |
|------|----------|
| **提出** | "We propose a novel X framework for Y, leveraging Z to achieve..." |
| **推导** | "We derive the closed-form/asymptotic expressions of X for Y under Z conditions." |
| **分析** | "We investigate/analyze the impact of X on Y in Z networks." |
| **优化** | "We formulate the optimization problem to minimize/maximize X subject to..." |
| **验证** | "We demonstrate/confirm that the proposed X outperforms Y by Z% in terms of..." |
| **对比** | "We selected different comparative baselines from the perspectives of X, Y, and Z..." |
| **贡献三层递进** | "1) We [动作] [方案]. By [工具/方法], we [进一步动作]. [结论句]." |

## 4. 结果呈现句式

| 功能 | 句式模板 |
|------|----------|
| **章节开头** | "In this section, numerical/simulation results are presented to verify the accuracy of..." |
| **引入图表** | "Fig. X plots the Y versus the Z, with [参数]." |
| **引入图表(变体)** | "Figure X illustrates/depicts/shows the Y versus the Z." |
| **趋势描述(上升)** | "The Y increases/improves/enhances with the increasing of X." |
| **趋势描述(下降)** | "The Y decreases/reduces/deteriorates as X increases." |
| **趋势描述(趋近)** | "The Y converges to an error floor / approaches X in the high SNR region." |
| **趋势描述(匹配)** | "The exact analytical curves match perfectly with Monte Carlo simulations." |
| **观察发现** | "It is observed from Fig. X that [发现]." |
| **另一观察** | "Another observation is that [额外发现]." |
| **多原因解释** | "This is due to the fact that [原因1]. Another reason is that [原因2]." |
| **原因解释** | "This is because / This is due to the fact that [原因]." |
| **现象强调** | "This phenomenon indicates that it is significant to select beneficial system parameters." |
| **结果引出(变体)** | "Numerical results indicate that: i)... ii)... iii)..." |
| **结果总起句** | "The simulation results verify the correctness of the formulas and yield the following insights: 1)... 2)... 3)..." |
| **验证结论** | "Numerical results verify the correctness of the theoretical analyses and demonstrate that..." |
| **条件限定结果** | "[发现], especially when [条件] / in contrast to [基准] / with the increasing of [参数]." |
| **双面论证** | "On the one hand, [正面效应]. This is because [解释]. On the other hand, [负面效应]. This is due to [原因]." |
| **trade-off权衡** | "[参数A] does not necessarily translate to better [性能]. Hence, it is crucial to consider the trade-off between [A] and [B]." |
| **多图联合分析** | "Fig. X(a): [条件A下的结果]. Fig. X(b): [条件B下的结果]. The main variation is that [对比发现]." |
| **顺序词串联** | "Numerical results firstly demonstrated [发现1]. Secondly, [发现2]. Finally, [发现3]." |

## 5. 过渡衔接句式

| 逻辑关系 | 句式模板 |
|----------|----------|
| **因果** | "Due to the balance between X and Y, introducing excessive Z is not helpful to reduce..." |
| **转折** | "However, this approach can result in larger errors from users with poor channel conditions." |
| **递进** | "Furthermore/Moreover, we also evaluate the impact of X on Y." |
| **对比** | "Compared to X, the proposed Y achieves superior Z at high SNRs." |
| **举例** | "For example, by adopting X strategy, the Y can effectively reduce Z." |
| **强调** | "It is worth noting that / It is worth pointing out that [重要发现]." |
| **总结** | "In summary / To summarize, [关键结论]." |

## 6. 论文组织句式

| 位置 | 句式模板 |
|------|----------|
| **论文结构** | "The rest of this paper is organized as follows. Section II presents... Section III discusses... Section IV provides... Finally, Section V concludes this paper." |
| **符号说明(标准版)** | "Notations: Scalars, vectors, and matrices are denoted by lower-case, bold-face lower-case, and bold-face upper-case letters, respectively." |
| **符号说明(续)** | "f_X(·) and F_X(·) denote the probability density function (PDF) and cumulative distribution function (CDF), respectively." |
| **符号说明(关键词版)** | "The key notations in this paper are presented as follows. (·)^H represents the conjugate transpose operation..." |
| **未来工作(标准)** | "A promising future research direction is to extend the proposed framework to [新场景] by considering [新因素]." |
| **未来工作(续)** | "Our future work will consider the impact of imperfect CSI and take into account more complex assumptions." |
| **未来工作(局限性出发)** | "The setting of [假设] may give rise to overestimated performance for [系统], hence our future work will [改进方向]." |
| **实际应用落点** | "From the perspective of practical applicability, [本文系统] is capable of satisfying [实际需求], where [用户X] can be [场景A] and [用户Y] can be [场景B]." |

## 7. 特殊学术表达

| 表达 | 使用场景 |
|------|----------|
| "It is worth noting that..." | 强调重要但非显而易见的发现 |
| "To gain further insights, ..." | 引入深层次分析 |
| "For the purpose of comparisons, ..." | 引入基准方案 |
| "As a further advance, ..." | 引入下一步分析 |
| "In light of the above works, ..." | 总结已有工作 |
| "To reap more insights, ..." | 引出渐近分析 |
| "On the basis of the analytical results, ..." | 从理论到讨论的过渡 |
| "It has been shown that..." | 被动语态确认已获得的结果 |
| "It was demonstrated that..." | 引用正文中的发现 |
| "It can be confirmed that..." | 强调结论的可信度 |
