# ieee-mg-citation 核心原则

## IEEE 引用格式基础

### 期刊论文
```
[1] A. Author, B. Author, and C. Author, "Title of article," IEEE Trans. Veh. Technol., vol. 73, no. 4, pp. 1234–1245, Apr. 2024.
```

### 会议论文
```
[2] A. Author and B. Author, "Title of paper," in Proc. IEEE Global Commun. Conf. (GLOBECOM), Kuala Lumpur, Malaysia, 2023, pp. 1–6.
```

### 书籍
```
[3] A. Author, Title of Book, xth ed. City, State, Country: Publisher, year.
```

### 标准格式要点
- 作者：名缩略 + 姓（如 J. Smith）
- 多人作者用 ", " 分隔，最后两人用 "and"
- 超过六位作者用 "et al."
- 期刊名使用标准缩写（IEEE 期刊缩写）
- 月份用三字母缩写（Jan., Feb., Mar., Apr., May, Jun., Jul., Aug., Sep., Oct., Nov., Dec.）

## 引用基本原则

1. **引用必要性**：所有非通用知识的技术声明需有文献支撑
2. **引用准确性**：引用信息需完整准确，不得编造
3. **引用相关性**：引用的文献需直接相关
4. **引用时效性**：优先引用最新研究成果
