# 审核核心原则

> **v1.2.0**：定量判定以 quantitative-baseline.md 为准；问题必须附"依据"；严重性判定操作化。

## 四维审核框架

| 维度 | 权重 | 检查内容 |
|------|:----:|----------|
| **结构性** | 35% | 章节结构是否完整，要素是否齐全 |
| **风格性** | 30% | 是否符合课题组全局风格画像 |
| **语言性** | 25% | 语法、用词、句式是否正确 |
| **格式性** | 10% | 引用格式、数学符号、缩略语是否规范 |

## 严重性标注规则（v1.2.0 操作化）

| 等级 | 判定标准 | 示例 |
|:----:|------|------|
| 🔴 **严重** | 与语料实测硬约束（✅ 级）直接冲突，或导致论文被拒的规范缺失 | 缺少贡献列表、Abstract 无编号结果、结论引入新引用、图描述用过去时（Fig. X plotted）、Conclusion 超 200 词 |
| 🟡 **中等** | 与软约束（💡 级）不一致，或硬约束存在瑕疵但不致命 | 时态不统一、句式过于复杂、词数略超范围、基准方案缺失（Results 无任何基准） |
| 🟢 **建议** | 可进一步优化，非必须；或语料低频可选手法未使用 | 可替换更精确的动词、可增加过渡词、未用顺序词串联、无对比表格 |
| ⚠ **存疑/需人工复核** | 证据不足：无语料依据的规范（如 System Model 检查）、无法客观判定的项 | System Model 的通用规范检查、主观的"过渡自然度" |

## 审核原则
1. **数据驱动**：所有判断基于 ieee-mg-share 的风格基准（style-profile/terminology/quantitative-baseline）与 ieee-mg-writing 的章节模板；**量化判定（词数/密度/条数）以 quantitative-baseline.md 数值为准，禁止自行另设区间**
2. **逐句标注**：每个问题标注到具体句子
3. **依据必填**：每个问题必须给出"依据"——触发的 check 项编号 + 对应语料模式或 baseline 数值（如 "check-abstract #8 / quantitative-baseline §1 Abstract 85-280 词"）
4. **可操作性**：每条建议都是可执行的（直接替换或修改）
5. **证据分级**：语料实测 > 课题组规范 > 外部通用知识；外部通用知识类检查（System Model）标注"存疑/通用规范"，不作为硬性判错依据
6. **合法变体保护**：语料实证的合法变体（"In this paper, we investigated" 开头、"-" 项目符号贡献列表、Fig. X plots 现在时、编号 i)/1) 均可）不得判为错误
