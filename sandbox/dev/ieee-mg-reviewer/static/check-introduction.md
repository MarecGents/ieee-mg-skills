# Introduction 审核清单

> 基于 ieee-mg-writing/static/section-introduction.md 的5层架构检查。
> **v1.2.0**：Layer 1 引用数修正（≥2）；引用密度标注局部适用；To the best 降为建议；贡献列表允许等价格式；新增子节检查与致命问题全映射。

## 结构性检查（10项）
- [ ] 1. **Layer 1**: 大背景段是否从宏观到微观
- [ ] 2. **Layer 1**: 是否引用背景文献（≥2 篇即可；语料实测可更多，如 FL 篇首段 [1]-[6]）
- [ ] 3. **Layer 2**: 技术演进段是否清晰
- [ ] 4. **Layer 2**: 综述密集段引用密度是否高（每句 ≥1 引用；**仅适用于综述密集段落，不适用于全文**）
- [ ] 5. **Layer 3**: 文献综述是否按主题分类（≥2类；编号段落式或子节式均可）
- [ ] 6. **Layer 3**: 是否覆盖关键和最新文献
- [ ] 7. **Layer 4**: 是否包含研究空白句（"To the best of our knowledge" 或变体；约 57% 论文精确使用，💡 建议非强制）
- [ ] 8. **Layer 5**: 贡献是否以列表格式呈现（1)2)3)4) 编号或 "-" 项目符号均可，语料实证两种）
- [ ] 9. **Layer 5**: 每个贡献是否含"动作+成果"（动作动词 + 方法/对象 + 成果/结论 三要素）
- [ ] 10. 论文组织段落是否存在

## 子节检查（v1.2.0 新增）
- [ ] 10a. "Motivations and Contributions" 类子节是否存在（约 90% 论文含，含变体标题；💡 推荐非强制）
- [ ] 10b. "Organization and Notation" 节是否存在（约 81% 论文含；含符号说明段落）

## 风格性检查
- [ ] 11. 引用句式是否多样（避免重复 "the authors in [x] investigated"；三型混用：过去时/现在完成时/现在时）
- [ ] 12. 时态是否正确（背景现在时，已有工作过去时/现在完成时/现在时三型均可）
- [ ] 13. 是否有符号说明段落（如含大量数学符号；💡 推荐）
- [ ] 14. 文献综述内部过渡手法是否多样化（避免 ≥3 句连续以单词过渡词 Furthermore/In addition/Additionally/Moreover/However 开头）

## 格式性检查
- [ ] 15. 文献引用是否全是编号格式 [x]
- [ ] 16. 缩略语首次出现是否已定义
- [ ] 17. 段落间过渡是否自然
