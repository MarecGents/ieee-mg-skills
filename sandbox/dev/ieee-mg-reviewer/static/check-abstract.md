# Abstract 审核清单

> 基于 ieee-mg-writing/static/section-abstract.md 的逐项检查。
> **v1.2.0**：量化判定以 quantitative-baseline.md 为准（词数 85-280、we 密度 6-8）；含数值检查项改为性能比较检查；新增判定方法与致命问题全映射。

## 结构性检查（10项）
- [ ] 1. 首句是否属于语料合法开头模式（"This paper investigates/proposes" 约 43%；技术主语式 "X has attracted growing interest..."；被动式 "A X system is investigated"；"Although..." 让步式约 5%）
- [ ] 2. 是否包含背景句（领域重要性）
- [ ] 3. 是否包含问题/动机句（💡 可选，约 10-20% 论文有独立问题句；缺失不判错）
- [ ] 4. 是否包含方法句（we propose/derive/formulate）
- [ ] 5. 是否包含结果句（Numerical/Simulation results ... that:，引出词 6+ 变体均可）
- [ ] 6. 结果是否以 i)/1) 无括号编号（"(i)(ii)(iii)" 括号形式判错）
- [ ] 7. 编号结果是否包含≥2条（语料 2-4 条，每条 15-30 词）
- [ ] 8. 词数是否在 85-280 范围内（quantitative-baseline §1；典型 130-260）
- [ ] 9. 句数是否在 5-12 范围内（课题组规范，💡）
- [ ] 10. 是否包含至少一个性能比较（与 OMA/PRIS/传统方案等基准对比；比较表达含 superior to/outperforms/exceeds/precede/compared to/compared with/than 等，判定时用词灵活）

## 风格性检查（5项）
- [ ] 11. 时态是否统一（一般现在时 + 现在完成时；描述论文内容不得用过去时）
- [ ] 12. "we" 密度是否适当（6-8/千词，实测 6.5，16/21 篇使用；quantitative-baseline §3。判定方法：统计 we 出现次数 ÷ 总词数 × 1000）
- [ ] 13. 是否避免口语化表达（含缩略形式 doesn't/it's）
- [ ] 14. 结果句是否与基准比较（100% 覆盖模式；**具体数值为可选项**，无数值不判错——语料 0/21 篇摘要含数值）
- [ ] 15. 是否包含特殊发现/权衡句（💡 语料高频特色，缺失不判错）

## 格式性检查（3项）
- [ ] 16. 所有缩略语首次出现是否已定义（Abstract 内即定义，语料 ipSIC 12/21、pSIC 11/21 篇）
- [ ] 17. 引用格式是否为 IEEE 编号格式
- [ ] 18. 数学符号是否斜体/粗体规范
