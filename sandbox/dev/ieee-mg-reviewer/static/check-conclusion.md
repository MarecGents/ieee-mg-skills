# Conclusion 审核清单

- [ ] 1. 是否以 "In this paper, we have investigated..." 开头（现在完成时）
- [ ] 2. 时态是否正确（现在完成时回顾工作）
- [ ] 3. 是否总结了核心工作（做了什么）
- [ ] 4. 是否总结了主要发现（发现了什么，含数值）
- [ ] 5. 与 Abstract 是否有差异（不复读摘要）
- [ ] 6. 是否没有引入新信息或新引用
- [ ] 7. 是否有未来工作方向（1-2句）
- [ ] 8. 未来工作是否具体可行
- [ ] 9. 长度是否在 200-400 词范围内
- [ ] 10. 是否包含 "A promising future research direction is..."

## 常见致命问题
| 问题 | 严重性 |
|------|:------:|
| 时态错误（用过去时） | 🔴 |
| 完全复制 Abstract | 🟡 |
| 无未来工作 | 🟡 |
| 引入新引用 | 🔴 |
| 未来工作泛泛而谈 | 🟢 |
