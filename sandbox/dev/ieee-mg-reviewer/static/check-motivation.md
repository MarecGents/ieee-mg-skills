# Motivation 审核清单

> **v1.2.0**：开头模式放宽（承上启下非强制）；动词多样性 ≥3 类；结论句降为建议；对比表维度注明非强制；致命问题全映射。

- [ ] 1. 是否以承上启下模式开头（While/Although/前述综述回顾；语料 While 类约 38%，非强制；开头突兀无过渡判 🟡）
- [ ] 2. 研究空白是否使用 "To the best of our knowledge" 或语料变体（has not been comprehensively explored / is not researched yet / this paper is the first / there is no related work to analyze 等）
- [ ] 3. 贡献点数量是否 ≥3个（语料 3-5 点）
- [ ] 4. 贡献点动词是否多样化（≥3 类；提出/推导/分析/验证 为推荐组合，顺序与数量可灵活——ASTARS covert 篇 propose→derive→derive→derive 语料实证）
- [ ] 5. 每个贡献点是否有结论句（💡 建议；语料部分贡献点无结论句，缺失不判错）
- [ ] 6. 对比表格(如有)特征行是否覆盖关键维度（约 5% 论文使用；源自 FL 篇 Table I 样例，非强制，无表不判错）
- [ ] 7. 引用是否覆盖关键和最新文献
- [ ] 8. 贡献点之间是否有逻辑递进
