# Motivation 审核清单

- [ ] 1. 是否以 "While/Although the aforementioned works" 开头
- [ ] 2. 研究空白是否使用 "To the best of our knowledge"
- [ ] 3. 贡献点数量是否 ≥3个
- [ ] 4. 贡献点动词是否覆盖 提出→推导→分析→验证
- [ ] 5. 每个贡献点是否有结论句
- [ ] 6. 对比表格(如有)特征行是否覆盖≥4个维度
- [ ] 7. 引用是否覆盖关键和最新文献
- [ ] 8. 贡献点之间是否有逻辑递进

## 常见致命问题
| 问题 | 严重性 |
|------|:------:|
| 非 "While" 开头 | 🟡 |
| 贡献点<3个 | 🔴 |
| 动词单一（全是 "propose"） | 🟡 |
| 无结论句 | 🟡 |
