# System Model 审核清单

- [ ] 1. 系统场景是否清晰描述（坐标/拓扑/假设）
- [ ] 2. 所有数学符号首次使用时是否定义
- [ ] 3. 变量是否斜体 $x$，向量是否粗体 $\mathbf{x}$
- [ ] 4. 信道模型是否明确命名（Rician/Nakagami/Rayleigh）
- [ ] 5. 优化问题是否完整（目标函数 + 约束条件）
- [ ] 6. 公式后是否有标点（, 或 .）
- [ ] 7. 公式编号是否连续
- [ ] 8. 算法步骤是否清晰（伪代码）
- [ ] 9. 是否提供复杂度分析
- [ ] 10. 是否有假设声明段落

## 常见致命问题
| 问题 | 严重性 |
|------|:------:|
| 符号未定义 | 🔴 |
| 变量格式不规范 | 🟡 |
| 信道模型未命名 | 🟡 |
| 优化问题不完整 | 🔴 |
| 无复杂度分析 | 🟢 |
